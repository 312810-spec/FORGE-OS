# ADR-0002 — v0.2 deterministic routing and scheduled health

Date: 2026-10-13
Status: implemented, awaiting release adoption

Implement a stdlib-only lexical callout router, local JSON checkpoint, test suite and weekly scheduled GitHub Actions checks. Derive concepts from outside agent frameworks but do not adopt heavy SDK dependencies prematurely. Keep authorization with user/platform controls rather than a keyword matcher.

Constraints: lexical classification is advisory and cannot understand nuanced permissions; checkpoints are single-writer; weekly CI verifies repository structure, not model outputs or live project workflow. No unattended external project mutations. If source comparisons are added later, pin sources and review licensing, security and supply-chain risks.
