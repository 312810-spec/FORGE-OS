# ADR-0004 — Evidence-first real-output evaluation

Date: 2026-10-13
Status: proposed for review

Manual import of real AI-generated output files is the first provider adapter. Capture has SHA-256 and provenance metadata; deterministic checks are executable; non-deterministic evaluation remains pending human review. Five representative domain scenarios are specified, not yet independently tested against real model outputs. The CI workflow validates code and suite readiness, not end-to-end live provider performance.

Provider API execution deliberately deferred: requires explicit credential connection, authenticated runtime, source/privacy policy, provider-specific sampling/cost instrumentation and independent baseline dataset. Approval required before release.
