# ADR-0003 — v0.3 evaluation before model integrations

Date: 2026-10-13
Status: implemented, pending CI validation

Build an offline, deterministic evaluation engine and capability selector with an evidence contract before adding paid APIs or agentic execution. Benchmark suites contain explicit assertions; candidate/baseline outputs must be collected independently. Include illustrative fixture data and label it as synthetic. Reject missing answers, duplicate/unknown case IDs and unknown checks. Fail closed on unavailable models. Treat case assertions as a narrow, inspectable starting point, not semantic quality judgments.

Risks: benchmark overfitting, fabricated evidence strings, nonrepresentative fixtures, stale catalog pricing, prompt injection in collected samples, leakage of protected data. Controls: human curation, permissions, anonymization, independent checks, documented scope and no automatic production deployment.
