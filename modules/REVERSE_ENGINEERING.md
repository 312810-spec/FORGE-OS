# FORGE Reverse Engineering v0.1.0

**Callouts:** `RE:`, `UI reverse:`, `UX reverse:`, `UI + UX reverse:`. Research is the default unless implementation is explicitly requested.

This module preserves the method from the user-supplied FORGE UI + UX Reverse-Engineering Module v1.0 (11 October 2026). The earlier narrow website investigations do not prove full REA parity.

## Route by access
1. Source authorized and available: inspect files, AST/symbols, tests and relevant runtime behavior.
2. Public website: inspect permissible UI/docs, scripts/styles and permitted network interactions; record provenance.
3. Compatible REA tool: check version and capabilities first.
4. REA worker/process failure: consider bounded, version-validated in-process static/semantic adapter; no claim of canonical evidence compatibility.
5. Bundler mismatch: identify build system and use its AST/module extraction methods. Do not infer module completeness from a detector's empty output.
6. Browser blocked: diagnose, bounded retry, then static alternatives. Mark live checks untested.
7. Screenshot/video only: record visible patterns and inferred behavior separately.
8. APK/native: require appropriate lawful tooling and permissions. Do not bypass access controls, paywalls, licensing or retrieve protected assets without authorization.

## Extract and adapt
Map trigger → state change → handler/module → data/network boundary → feedback → recovery. Record source URL/version/hash/offset, direct observation, inference, risk and verification status. Favor reusable interaction patterns rather than unauthorized replication of proprietary assets or premium content.

## High-value reference contracts
- Tabs: role/association, visible focus, keyboard directional behavior, deliberate activation and reduced-motion support.
- Bulk select: stable IDs, mixed-state aggregates, clearly stated page/all-matching scope, accurate counts and filter/pagination policy.
- Bulk mutation: complete/partial/rejected/unknown outcomes, targeted retry, truthful undo.
- Save: draft/pending/confirmed/conflict/failed states, preserved edits, persistence as authoritative.

## Pilot evidence limits
Earlier research reportedly parsed ten scripts in each of two page investigations; a homepage command player had four live tab selections with a Right Arrow navigation defect, and a separate bulk-actions reference tested video Pause but did not expose live checkbox controls. Broad semantic scans exceeded memory; narrow scans succeeded. These are historical user-provided pilot findings, **not rerun by this repository release**.

Supplement with current reference notes and reverify before relying on details.
